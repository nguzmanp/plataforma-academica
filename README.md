# Plataforma Académica Básica

## Descripción
Este proyecto contiene los archivos iniciales para una plataforma académica web. Su finalidad no es desarrollar una aplicación completa, sino servir como base para poner en práctica el flujo de trabajo colaborativo utilizando Git y GitHub, incluyendo el uso de ramas, registro de commits, carga de cambios y revisión mediante Pull Requests.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 📂 Estructura del Repositorio

El proyecto cuenta con los archivos esenciales para iniciar un desarrollo web básico:

```
📁 plataforma-academica
├── 📄 index.html      # Estructura principal de la plataforma
├── 📄 style.css       # Estilos visuales de la interfaz
├── 📄 script.js       # Lógica básica e interacciones (Opcional)
└── 📄 README.md       # Documentación del proyecto
```
